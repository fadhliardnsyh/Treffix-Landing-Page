# Treffix company profile

Bilingual (Bahasa Indonesia and English) company profile built with Next.js App Router, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Run the project checks with `npm run lint` and `npm run build`.

The root path redirects to `/id`. English content is available at `/en`.

The dashboard illustrations are concept visuals. Set `NEXT_PUBLIC_TREFFIX_CONTACT_URL` in `.env.local` to Treffix's approved sales email (`mailto:...`) or inquiry URL. No contact destination was included in the source brief, so the CTA currently falls back to the solutions section.
